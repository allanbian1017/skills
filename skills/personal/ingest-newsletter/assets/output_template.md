# Newsletter Summary — 摘要輸出格式

針對「每一封」電子報，嚴格依照以下格式獨立產生內容：

```markdown
# [寄件者] - [電子報標題]

## 來源
- [列出電子報的寄件者, 標題與文章或是電子報的網址]

## 📝 核心總結（Executive Summary）
- [用 1-3 句話精準概括這封電子報的最主要目的或主旨]

## 📌 關鍵重點（Key Highlights）
*(請依據原文主題進行分類，確保不漏掉任何細節)*
- **[主題分類 1]**：[詳細重點說明，必須包含原文提到的具體數據、名詞 or 事件]
- **[主題分類 2]**：[詳細重點說明]
- *(依此類推)*

## 🚀 行動呼籲 / 期限（Action Items / Deadlines）
- [列出原文中要求讀者執行的動作、活動報名、截止日期等。若原文無此內容，請填寫「無特別行動呼籲」]

## ⚠️ 資訊免責聲明（Disclaimers）
- [若原文中有任何語意不清、連結缺失或指代不明的地方，請在此列出提醒用戶。若資訊皆完整清晰，此項可省略]
```

---

## 檔案命名規則

> 📄 Read `../content-summary/references/filename_rules.md` for sanitisation rules.

- **儲存路徑**：`./reports/Newsletter_YYYY_MM_DD/`（以執行當天日期作為目錄）
- **檔案名稱格式**：`[寄件者]_[電子報標題].md`
- 確保保留每個區塊的完整欄位，**寫入時嚴禁省略任何欄位**
