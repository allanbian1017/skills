# Team Code Review Preferences

This file records project-specific review preferences and conventions learned from human reviewer feedback.
Entries in this file take precedence over baseline style guide rules during review evaluation (in-memory) without altering baseline style guide files on disk.

## Format Specification

When a preference is learned via the Learn mode proposing and confirming workflow, append an entry using the following template:

```markdown
### <Descriptive Title>
- **Language**: <language identifier, e.g., go, typescript, python, or common>
- **Preference**: <Specific rule or convention to follow>
- **Rationale**: <Why this rule is preferred by the team>
- **Source**: [PR #<number> comment](<url>)
- **Learned**: <YYYY-MM-DD>
```
