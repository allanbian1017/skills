# Agent Skills Repository

This repository is a curated collection of AI agent skills utilized by the author to automate workflows, assist in daily tasks, and enhance overall productivity.

## Overview

These skills define the instructions, workflows, and capabilities of AI agents across various domains. Collecting them in a centralized repository makes it easier to maintain, refine, reuse, and scale agentic workflows over time.

## Structure

The skills are organized into the following logical categories within the `skills/` directory:

- **`engineering/`**: Skills related to software development, coding assistance, architecture design, and technical documentation.
- **`productivity/`**: Workflows tailored for task management, newsletter and content summarization, and knowledge management.
- **`personal/`**: Skills customized for personal routines, scheduling, and private workflows.
- **`misc/`**: Miscellaneous skills and experimental AI workflows.

## Usage

Each skill category contains specific instructions or markdown files that outline the purpose, behavior, and expected outputs of the agent. These can be integrated or referenced in your AI agent environments to replicate these capabilities.
